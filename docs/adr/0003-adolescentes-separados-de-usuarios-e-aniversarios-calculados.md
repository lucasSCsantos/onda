# Adolescentes separados de Usuários; aniversários calculados

O cadastro de Adolescentes é independente do de Usuários, para permitir ligar um acesso no futuro sem migrar dados e para manter dados de menores fora do controle de contas. Aniversários nunca são gravados como Eventos: são calculados a partir da data de nascimento, o que evita duplicidade e resolve o 29/02.
